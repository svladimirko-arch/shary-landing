# Золотой Шар — праздничный лендинг

Продающий одностраничный лендинг для производства ёлочных шаров с нанесением логотипа.

## Стек

- Один самодостаточный `index.html` (CSS и JS инлайн, без сборки)
- Изображения в `assets/img/` — сгенерированы ИИ
- Шрифты: Playfair Display + Manrope (Google Fonts, кириллица)

## Фишки

- Снегопад на canvas, заснеженные еловые лапы с шарами по краям (покачивание), мерцающая гирлянда-огоньки
- Обратный отсчёт до Нового года, конфетти при отправке формы
- Каталог, технологии нанесения, таблица цен по тиражам, портфолио, этапы, FAQ, форма с валидацией
- Адаптив 375–1920 px, поддержка `prefers-reduced-motion`

## Запуск

```bash
npm run dev   # статический сервер на http://127.0.0.1:7100/
```

Или просто открыть `index.html` в браузере.
